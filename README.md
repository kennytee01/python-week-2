## What is inside

| Topic | What I practised |
|---|---|
| OOP | Classes, objects, `__init__`, `__str__` and methods |
| Inheritance | Parent and child classes, `super()`, overriding and multilevel chains |
| Iterators | `iter()`, `next()`, StopIteration, and custom iterators such as CountDown, EvenNumbers, Fibonacci and FileLineReader |
| Polymorphism | The same method name across classes, abstract classes, and `len()` on different types |
| Scope | Local, global, enclosing and built in scope, `global`, `nonlocal`, and hiding the built in `len` |

## Project: Library Management System

* Book, EBook and PrintedBook classes
* Member, StudentMember and TeacherMember classes with different borrowing limits (students 3, teachers 5)
* Iterators for the library and for a member's borrowed books
* A protected borrowed books list and a private library name, with getters and setters
* Availability tracking, search by title or author, and a class level count of all borrowed books
* A demo at the end of the notebook that runs every feature

## What I learned

Understanding how the pieces connect matters more than memorising keywords.
